# Credits and AI assistance

Pupil Check was created by Aniruddh Maheshwari and Vivaan Mahajan for the 2026
Congressional App Challenge, Arkansas District 3.

The team chose the app's scope and tasks, directed implementation, reviewed
changes, tested on a physical iPhone, and prepared the submission narration and
video. Real-device feedback informed calibration recovery, instructions, result
wording, saving, and timing fixes.

OpenAI Codex assisted with code generation and revision, debugging, automated
checks, integration, interface wording, and drafting submission text. This is
AI-assisted development, not a claim that every line was written unaided. The
team's application provides the final disclosure, including any other tools used.

The app uses Apple's system frameworks: SwiftUI, ARKit, SceneKit, Swift Charts,
CoreMotion, and AVFAudio. See [third-party notices](../THIRD_PARTY_NOTICES.md).
